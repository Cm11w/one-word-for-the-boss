## The word

**Meetingizer** — 11 characters.

A boss who turns every five-minute question into a meeting. One word, no
caption, no explanation: it stands on its own. It is funny because every
office has one, true because the habit is instantly recognisable, fresh
because it is a coinage rather than the first word anyone reaches for, and it
travels — a meetingizer runs a kitchen, a warehouse, or an office with the
same calendar full of meetings about meetings.

## How it works

`main.ts` is a dependency-free Node program. It validates the word against
the competition gate (UTF-8 text, 1–30 characters, not only white space, a
single word with no spaces) and writes it to `/output/entry.txt`.

```sh
node main.ts
```

The output is deterministic: every run writes the exact same bytes.
