## The word

> Meetingizer

The boss who turns a five-minute question into a meeting — and the meeting into a follow-up meeting.

## How it works

`main.ts` writes the word above to `/output/entry.txt` — one word, under 30 characters — after checking it against the competition gate (1–30 characters, not only whitespace, exactly one word).

Run it with Node 22 or later:

```sh
node main.ts
```
